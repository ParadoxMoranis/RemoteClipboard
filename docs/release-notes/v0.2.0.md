# Remote Clipboard v0.2.0

本版本聚焦桌面客户端体验与文件传输验证。Linux Wayland 与 Windows 客户端现在共用同一套锐利、直角的 Qt 界面，并提供独立亮色/暗色撞色主题和 English/简体中文运行时切换。

## 主要变化

- 统一 Linux 与 Windows 主界面，改善窗口缩放时的控件伸缩和设置页滚动。
- 新增持久化亮色/暗色主题，状态、主操作和错误使用清晰的高对比配色。
- 新增 English/简体中文选项，覆盖主界面、设置、托盘、状态、日志和常用对话框。
- 修复设置窗口首次打开时未载入当前连接档案的问题。
- Windows 端口输入改为有范围约束的数值控件，并新增 `Ctrl+,` 设置快捷键。

## 文件功能重点测试

本地及发布 CI 会执行真实 TCP 服务端集成测试，覆盖双客户端认证与转发、非法 Base64、SHA-256 不匹配、路径净化、分块乱序/重复拒绝、最终文件大小与摘要一致性，以及 TLS 1.3 连接。

建议下载后用两台客户端重点验证：

1. 复制总量小于 4 MiB 的单文件和多文件，确认接收目录生成批次目录且内容一致。
2. 复制大于或等于 4 MiB 的文件，确认走 512 KiB 顺序分块并在完成后一次性可见。
3. 重复发送同名文件，确认不会覆盖已有文件；中途断网后确认未完成文件不会被当作成功文件使用。
4. 分别测试 Linux 到 Windows、Windows 到 Linux，并对源文件与接收文件运行 `sha256sum`（Windows 可用 `certutil -hashfile <file> SHA256`）。

## 下载选择

- 服务端：Debian 12 `amd64` DEB，Fedora 42 `x86_64` RPM。
- Linux 客户端：Debian 12 DEB，Fedora 42 RPM，Arch Linux 本地 `pkg.tar.zst`。
- Windows 客户端：x86_64 ZIP，包含 EXE、Qt、OpenSSL 和 MinGW 运行库。
- 源码：统一 source ZIP，包含 `build-server-from-source.sh` 和 `build-client-from-source.sh`。
- 完整性：`SHA256SUMS` 与 GitHub/Sigstore 构建证明。

## 兼容与边界

本版本继续使用 JSON Lines v1 单工作区广播协议，没有数据库或网络协议破坏性变更。生产环境仍应启用 TLS 1.3，并使用外部密码文件；JWT、设备配对、离线队列、插件系统和自动更新尚未实现。仓库尚未选定许可证，正式再分发前需完成许可证审查。
