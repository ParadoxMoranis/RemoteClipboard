# Remote Clipboard v0.1.0

首个可测试的安全基线版本，统一 Linux/Windows 构建、v1 协议、TLS 1.3、文件完整性校验、SQLite 元数据和自动化测试。

## 下载选择

- 服务端：Debian 12 `amd64` DEB，Fedora 42 `x86_64` RPM。
- Linux 客户端：Debian 12 DEB，Fedora 42 RPM，Arch Linux 本地 `pkg.tar.zst`。
- Windows 客户端：仅提供 x86_64 ZIP，已包含 Qt、OpenSSL 和 MinGW 运行库。
- 源码：统一 source ZIP，包含 `build-server-from-source.sh` 和 `build-client-from-source.sh`。

## 安全提醒

生产服务端默认要求 TLS 1.3、用户名和外部密码文件。明文模式只能通过 `--development --no-tls` 显式启用，且不得暴露到不可信网络。

## 当前边界

v0.1 使用单工作区广播协议；JWT、设备配对、离线队列、插件系统和自动更新属于后续版本。仓库尚未选定许可证，正式再分发前需完成许可证审查。
