# Remote Clipboard v0.2.1

本版本为 Windows 客户端增加标准 x86_64 安装器，同时保留 v0.2.0 的便携 ZIP、锐利风格界面、中英双语和文件传输能力。

## Windows 安装器

- 推荐下载 `RemoteClipboard-client-windows-x64-setup.exe`。
- 默认安装到当前用户的应用目录，不要求管理员权限。
- 创建开始菜单快捷方式，可选创建桌面快捷方式。
- 提供 Windows“已安装的应用”卸载入口，并支持后续版本覆盖升级。
- GitHub Windows runner 会实际执行一次静默安装和卸载，确认 EXE 与运行库能够正确部署。

需要免安装使用时，继续下载 `RemoteClipboard-client-windows-x64.zip`，解压后运行 `bin/remote-clipboard-windows.exe`。

## 文件功能验证

自动化测试继续覆盖小文件 bundle、大文件顺序分块、最终大小与 SHA-256、非法 Base64、摘要不匹配、乱序/重复分块拒绝、路径净化和 TLS 1.3 双客户端传输。

## 其他下载

- 服务端：Debian 12 `amd64` DEB，Fedora 42 `x86_64` RPM。
- Linux 客户端：Debian 12 DEB，Fedora 42 RPM，Arch Linux 本地 `pkg.tar.zst`。
- 源码：干净的统一 source ZIP，包含服务端与客户端源码构建脚本。
- 完整性：`SHA256SUMS` 与 GitHub/Sigstore 构建证明。

## 安全与兼容

安装器当前没有 Authenticode 代码签名证书，Windows SmartScreen 可能显示“未知发布者”；请从本 Release 下载并核对 `SHA256SUMS`。网络协议和配置格式与 v0.2.0 兼容，不需要迁移。
